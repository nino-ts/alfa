# create-alfa

Scaffold de novas aplicações [alfa](https://github.com/nino-ts/alfa).

> ⏳ **Ainda não publicado no npm.** Use o clone com `bun link`:
>
> ```bash
> git clone https://github.com/nino-ts/alfa && cd alfa && bun install
> cd packages/alfa && bun link
> cd ../create-alfa && bun link
> # em seguida: bunx create-alfa myapp
> ```

```bash
bunx create-alfa myapp
bunx create-alfa myapp --template react
```

## Templates

- `hypermedia` (default) — HTMX + Alpine em `pages/*.html`
- `react` — `pages/*.tsx` com Bun fullstack
